Instalación

Carga primero el CSS y el JavaScript de Leaflet y después leaflet-providersESP. El plugin funciona directamente con Leaflet; cargar leaflet-providers es opcional.

Vía CDN

Para usar la versión publicada v1.4.0 con Leaflet 1.9.4:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.css">
<script src="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js"></script>
<script src="https://cdn.jsdelivr.net/gh/dieghernan/leaflet-providersESP@v1.4.0/dist/leaflet-providersESP.min.js"></script>

Para seguir el desarrollo en main, sustituye solo el script del plugin por:

<script src="https://cdn.jsdelivr.net/gh/dieghernan/leaflet-providersESP@main/dist/leaflet-providersESP.min.js"></script>

La URL de main sigue esa rama y puede cambiar. Para probar los cambios sin publicar de tu copia del repositorio, usa los archivos locales.

Local

Copia dist/leaflet-providersESP.min.js junto a tu archivo HTML y sustituye el script del plugin en el ejemplo completo de abajo por:

<script src="./leaflet-providersESP.min.js"></script>

También puedes copiar dist/leaflet-providersESP.js y usar src="./leaflet-providersESP.js" para cargar el código sin minificar. Los archivos están en dist/. Mantén las referencias al CSS y al JavaScript de Leaflet antes del plugin.

Ejemplos

Un mapa completo

Guarda este ejemplo como index.html y ábrelo en el navegador. El contenedor del mapa necesita una altura explícita para ser visible.

<!doctype html>
<html lang="es">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Mapa de España</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.css">
    <script src="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js"></script>
    <script src="https://cdn.jsdelivr.net/gh/dieghernan/leaflet-providersESP@v1.4.0/dist/leaflet-providersESP.min.js"></script>
    <style>
        html, body { height: 100%; margin: 0; }
        #map { height: 100%; width: 100%; }
    </style>
</head>
<body>
    <div id="map"></div>
    <script>
var map = L.map('map').setView([40.4166, -3.7038], 12);
L.tileLayer.providerESP('IGNBase.Todo').addTo(map);
    </script>
</body>
</html>

Varias capas

Los siguientes fragmentos sustituyen el contenedor y el script del mapa del ejemplo completo. Conserva los estilos y las dependencias del <head>.

<div id="map"></div>
<script>
var map2 = L.map('map', { center: [37.053333, -3.311389],
	zoom: 15 });
L.tileLayer.providerESP('LiDAR').addTo(map2);
L.tileLayer.providerESP('MDT.CurvasNivel').addTo(map2);
L.tileLayer.providerESP('NombresGeograficos').addTo(map2);
</script>

leaflet-providersESP + leaflet-providers

<div id="map"></div>
  <script src="https://cdn.jsdelivr.net/npm/leaflet-providers@4.0.0/leaflet-providers.js"></script>
<script>
var map3 = L.map('map', { center: [38.8, -5.3],
	zoom: 5 });
var base = { 'OpenStreetMap.Mapnik': L.tileLayer.provider('OpenStreetMap.Mapnik').addTo(map3),
	'Esri.WorldTopoMap': L.tileLayer.provider('Esri.WorldTopoMap') };
var over = { 'Terremotos Ult. 30dias': L.tileLayer.providerESP('Geofisica.Terremotos30dias', { transparent: true }).addTo(map3) };
L.control.layers(base, over, { collapsed: true }).addTo(map3);
</script>

Elegir una capa

Cada capa se identifica con Proveedor.Variante, por ejemplo IGNBase.Gris. Si omites la variante se usa la predeterminada del proveedor: IGNBase y IGNBase.Todo muestran la misma cartografía, aunque cada llamada crea un objeto Leaflet distinto.

Busca una capa en el catálogo, comprueba su aspecto y copia su llamada a L.tileLayer.providerESP(). La referencia de capas explica qué representa cada nombre y sus limitaciones de cobertura, escala y disponibilidad.

Fondos, superposiciones y opciones

Un fondo aporta la cartografía principal. Las superposiciones añaden información sobre él, como límites administrativos o curvas de nivel. Algunas capas solo muestran información a partir de un nivel de zoom o dentro de su cobertura.

Puedes pasar opciones de Leaflet como segundo argumento:

L.tileLayer.providerESP('UnidadesAdm.Limites', {
    opacity: 0.7
}).addTo(map);

El visor muestra un mapa a toda página con una franja colapsable. En las pestañas Fondos y Transparencias, busca y marca las capas que quieras incorporar al selector y mostrar directamente en el mapa. Un fondo nuevo sustituye al fondo visible; las transparencias se acumulan. La clasificación se deduce de las opciones de transparencia y opacidad del proveedor.

Pulsa el icono de capas apiladas, en la esquina superior derecha, para elegir un fondo y activar o desactivar transparencias con el control estándar de Leaflet. Desmarcar una capa en la franja la retira del selector y del mapa. Puedes colapsar la franja para dedicar más espacio al mapa. El selector se abre al hacer clic y se cierra con ×, Escape o un clic fuera. El número sobre el icono indica cuántas capas hay en el selector. La etiqueta Activa identifica una capa habilitada en el mapa; En el selector indica que está disponible, pero desactivada. Ninguna de las dos etiquetas garantiza que haya datos en la zona o escala actual. Los avisos Cargando y Error de carga describen las peticiones de teselas, tanto en el visor como en Preview. En móvil, la franja comienza cerrada. Puedes abrirla y usar Cerrar y ver mapa para colapsarla sin cambiar tu selección.

El botón Localizarme, junto al zoom, solicita tu ubicación únicamente al pulsarlo. Para comparar miniaturas y copiar código con o sin el plugin, usa Preview.

La lupa, junto a los controles del mapa, abre la búsqueda de direcciones de CartoCiudad. Introduce calle, número y municipio, pulsa Buscar y elige un resultado para centrar el mapa. Puedes cerrar el formulario con ×, Escape o un clic fuera; las capas seleccionadas se conservan.

En el visor y en Preview, Restablecer vista inicial recarga la página y recupera el fondo inicial, la posición y el zoom del mapa, los filtros y los controles predeterminados. También elimina los marcadores de ubicación y búsqueda.

Compatibilidad y cambios de nombres

La API de este plugin es L.tileLayer.providerESP(). La de leaflet-providers es L.tileLayer.provider(). Puedes usar ambas en el mismo mapa; no necesitas cargar leaflet-providers si solo usas las capas de este proyecto.

Nombres de variantes y deprecaciones

Desde la versión 1.4.0, los nombres recomendados son CaminoDeSantiago.CaminosNordeste y Geofisica.HazardArea2002 (mapa NCSE-02 de 2002). Los nombres anteriores, CaminoDeSantiago.CaminosCatalanes y Geofisica.HazardArea, siguen funcionando como alias de las mismas capas.

Las demás variantes de Copernicus usan los servicios oficiales de EEA y conservan sus nombres y los productos de 2012/2015. La cobertura sigue los productos europeos. ForestLeaf solicita EPSG:4326 automáticamente, también en el mapa Mercator predeterminado de Leaflet. Las otras variantes usan EPSG:3857. Las peticiones combinan las resoluciones o las capas ráster y vectoriales disponibles para que el servicio seleccione la representación adecuada según la escala.

Copernicus.RiparianGreen está deprecada: el servicio no está disponible y no se ha identificado un WMS oficial equivalente. La llamada sigue admitida por compatibilidad y muestra un aviso en la consola una vez por página. Esta variante ya no se incluye en las listas de capas disponibles ni en las previsualizaciones.

Si el mapa no se ve

  • Comprueba que el contenedor tiene altura y que cargas el CSS de Leaflet.
  • Carga el JavaScript de Leaflet antes del plugin y crea el mapa después del contenedor HTML.
  • Acércate a la zona de cobertura: una capa puede no tener datos en todo el territorio o a todas las escalas.
  • Consulta la consola y la pestaña de red del navegador. Una petición fallida puede deberse al servicio remoto, a sus condiciones de acceso o a CORS.
  • Si una capa transparente parece vacía, añade un fondo y prueba a acercarte a su zona de cobertura.

Atribución y condiciones de uso

Mantén visible el control de atribución de Leaflet. El plugin incorpora la atribución configurada para cada capa, pero debes consultar las condiciones del organismo antes de reutilizar sus mapas. La licencia MIT del código no sustituye las condiciones de los servicios cartográficos.

La presencia de una capa en el catálogo no garantiza su disponibilidad. Consulta las incidencias conocidas y la auditoría de servicios para conocer las comprobaciones realizadas y sus fechas.
