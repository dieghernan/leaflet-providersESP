Leaflet-providersESP

Plugin para Leaflet con información de organismos españoles

Leaflet-providersESP es un plugin para mapas Leaflet que proporciona un acceso fácil a diferentes servicios web de mapas (WMS) y servicios web de mapas teselados (WMTS) proporcionados por organismos públicos de España, como el Instituto Geográfico Nacional (IGN) o el servicio de Infraestructura de Datos Espaciales de España (IDEE) del Consejo Superior Geográfico.

Este plugin es compatible con el plugin leaflet-providers.

Instalación

Carga primero el CSS y el JavaScript de Leaflet y después leaflet-providersESP. El plugin funciona directamente con Leaflet; cargar leaflet-providers es opcional.

Vía CDN

Para usar la versión publicada v1.4.0 con Leaflet 1.9.4:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.css">
<script src="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js"></script>
<script src="https://cdn.jsdelivr.net/gh/dieghernan/leaflet-providersESP@v1.4.0/dist/leaflet-providersESP.min.js"></script>

Para seguir el desarrollo en main, sustituye solo el script del plugin por:

<script src="https://cdn.jsdelivr.net/gh/dieghernan/leaflet-providersESP@main/dist/leaflet-providersESP.min.js"></script>

La URL de main sigue esa rama y puede cambiar. Para probar los cambios sin publicar de tu copia del repositorio, usa los archivos locales.

Local

Copia dist/leaflet-providersESP.min.js junto a tu archivo HTML y sustituye el script del plugin en el ejemplo completo de abajo por:

<script src="./leaflet-providersESP.min.js"></script>

También puedes copiar dist/leaflet-providersESP.js y usar src="./leaflet-providersESP.js" para cargar el código sin minificar. Los archivos están en dist/. Mantén las referencias al CSS y al JavaScript de Leaflet antes del plugin.

Demos

Página completa

Guarda este ejemplo como index.html y ábrelo en el navegador. El contenedor del mapa necesita una altura explícita para ser visible.

<!doctype html>
<html lang="es">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Mapa de España</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.css">
    <script src="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js"></script>
    <script src="https://cdn.jsdelivr.net/gh/dieghernan/leaflet-providersESP@v1.4.0/dist/leaflet-providersESP.min.js"></script>
    <style>
        html, body { height: 100%; margin: 0; }
        #map { height: 100%; width: 100%; }
    </style>
</head>
<body>
    <div id="map"></div>
    <script>
var map = L.map('map').setView([40.4166, -3.7038], 12);
L.tileLayer.providerESP('IGNBase.Todo').addTo(map);
    </script>
</body>
</html>

Varias capas

Los siguientes fragmentos sustituyen el contenedor y el script del mapa del ejemplo completo. Conserva los estilos y las dependencias del <head>.

<div id="map"></div>
<script>
var map2 = L.map('map', { center: [37.053333, -3.311389],
	zoom: 15 });
L.tileLayer.providerESP('LiDAR').addTo(map2);
L.tileLayer.providerESP('MDT.CurvasNivel').addTo(map2);
L.tileLayer.providerESP('NombresGeograficos').addTo(map2);
</script>

leaflet-providersESP + leaflet-providers

<div id="map"></div>
  <script src="https://cdn.jsdelivr.net/npm/leaflet-providers@4.0.0/leaflet-providers.js"></script>
<script>
var map3 = L.map('map', { center: [38.8, -5.3],
	zoom: 5 });
var base = { 'OpenStreetMap.Mapnik': L.tileLayer.provider('OpenStreetMap.Mapnik').addTo(map3),
	'Esri.WorldTopoMap': L.tileLayer.provider('Esri.WorldTopoMap') };
var over = { 'Terremotos Ult. 30dias': L.tileLayer.providerESP('Geofisica.Terremotos30dias', { transparent: true }).addTo(map3) };
L.control.layers(base, over, { collapsed: false }).addTo(map3);
</script>

Proveedores disponibles

Nombres de variantes y deprecaciones

Desde la versión 1.4.0, los nombres recomendados son CaminoDeSantiago.CaminosNordeste y Geofisica.HazardArea2002 (mapa NCSE-02 de 2002). Los nombres anteriores, CaminoDeSantiago.CaminosCatalanes y Geofisica.HazardArea, siguen funcionando como alias de las mismas capas.

Las demás variantes de Copernicus usan los servicios oficiales de EEA y conservan sus nombres y los productos de 2012/2015. La cobertura sigue los productos europeos. ForestLeaf solicita EPSG:4326 automáticamente, también en el mapa Mercator predeterminado de Leaflet. Las otras variantes usan EPSG:3857. Las peticiones combinan las resoluciones o las capas ráster y vectoriales disponibles para que el servicio seleccione la representación adecuada según la escala.

Copernicus.RiparianGreen está deprecada: el servicio no está disponible y no se ha identificado un WMS oficial equivalente. La llamada sigue admitida por compatibilidad y muestra un aviso en la consola una vez por página. Esta variante ya no se incluye en las listas de capas disponibles ni en las previsualizaciones.
