# Social cards

The HTML layout uses Inter and Inter Tight from Chulapa’s GitDev skin. The
title has an explicit line break and the text stays in its own column, leaving
room for the map and attribution at both sharing sizes.

Serve the repository root, open `dev/social/social-card.html` and wait for
the local fonts and map to load. Capture JPEG screenshots at 1200 × 630 for
`docs/assets/social-preview.jpg` and 1280 × 640 for
`docs/assets/github-preview.jpg`, using 100% browser zoom.

The source map is `social-map.jpg`, with IGN attribution preserved in the
card. Font files retain their OFL licenses.
